# Sprint 001 Acceptance Criteria

This sprint is complete when:

- [ ] All Priority 1 fields from the proposal are mapped to schema columns.
- [ ] PostgreSQL schema draft exists in `docs/DATA_MODEL.md` with table definitions and relationships.
- [ ] REST API surface is documented in `docs/API.md` (at minimum: CRUD for Song, Album, Artist; search).
- [ ] MCP interface is sketched (tools, inputs, outputs).
- [ ] `docs/ARCHITECTURE.md` describes the system components and data flow.
- [ ] `docs/VALIDATION.md` describes how data integrity will be verified.
- [ ] All open questions are either answered and moved to `DECISIONS.md`/`DOMAIN.md`, or escalated with an owner and due date.
- [ ] `planning/STATE.md` is updated to reflect sprint completion.
